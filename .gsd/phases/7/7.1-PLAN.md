# Plan 7.1: Setup Hono API and In-Memory Coordinator

## Objective
Initialize the `examples/social-server` package with a Hono API and an in-memory Contest Coordinator. This fulfills the `API: Create Contest, Submit Vote` and `Contest Coordinator` requirements of Phase 7.
