# Plan 2.1: Cycle Guardrails

## Objective
Implement cycle detection to identify and handle non-transitive preferences (e.g., A > B > C > A) which confuse the Gaussian model. Use Tarjan's algorithm to detect Strongly Connected Components (SCCs).

## Context
- .gsd/SPEC.md (Recall "Robustness against cycles")
- .gsd/phases/2/RESEARCH.md (Decision: Tarjan's SCC)
- src/engine/engine.ts
- src/types.ts
