# Plan 1.1: Foundation (Types, Math, RNG)

## Objective
Establish the mathematical and structural foundation for the Taste Engine. This includes the statistical functions required for the Gaussian updates, a deterministic Random Number Generator (RNG), and the core type definitions.

## Context
- .gsd/SPEC.md
- .gsd/ARCHITECTURE.md
- .gsd/phases/1/RESEARCH.md
- src/types.ts (to be created)
- src/utils/statistics.ts (to be created)
- src/utils/rng.ts (to be created)

## Tasks

<task type="auto">
  <name>Implement Core Types and Constants</name>
  <files>src/types.ts, src/defaults.ts, src/utils/constants.ts</files>

<task type="auto">
  <name>Implement Statistical Utils</name>
  <files>src/utils/statistics.ts, test/utils/statistics.test.ts</files>
  <action>
    Implement zero-dependency statistical functions needed for TrueSkill:
    - `erf(x)`: Error function (Abramowitz & Stegun 7.1.26 or similar high-precision approx)
    - `erfinv(x)`: Inverse error function (Acklam's algorithm)
    - `pdf(x)`: Standard normal PDF
    - `cdf(x)`: Standard normal CDF (using erf)
    - `ppf(x)`: Inverse CDF (using erfinv)
    
    Add safeguards: Clamp `erfinv` inputs to avoid Infinity/NaN for extreme values (e.g., +/- 8 sigma equivalent).
    Write unit tests verifying these against known standard normal table values.
  </action>
  <verify>npx vitest run statistics</verify>
  <done>All statistical functions pass tests with high precision (e.g., 1e-5 tolerance).</done>
</task>

<task type="auto">
  <name>Implement Deterministic RNG</name>
  <files>src/utils/rng.ts, test/utils/rng.test.ts</files>
  <action>
    Implement a seedable RNG class using **Mulberry32**.
    - Constructor accepts a seed (number or string).
    - Methods: `next()`, `nextInt(min, max)`, `nextFloat()`.
    - Ensure it is strictly deterministic (same seed = exact same sequence).
  </action>
  <verify>npx vitest run rng</verify>
  <done>RNG passes determinism tests.</done>
</task>
