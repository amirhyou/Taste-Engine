# Plan 1.2: Core Model (Gaussian updates)

## Objective
Implement the core ranking logic. This involves the "TrueSkill-like" update mechanism (Gaussian updates) that adjusts item ratings based on comparison outcomes.

## Context
- .gsd/phases/1/RESEARCH.md (Custom Gaussian Updates)
- src/types.ts
- src/utils/statistics.ts

## Tasks

<task type="auto">
  <name>Implement Gaussian Model Logic</name>
  <files>src/model/gaussian.ts, test/model/gaussian.test.ts</files>
  <action>
    Implement the update equations for a 2-player game (Thurstone-Mosteller model).
    - Function: `computeUpdate(winner: Item, loser: Item, config: RunConfig) -> { winnerNew: Item, loserNew: Item }`
    - Steps:
        1. Calculate signal `v` and variance `w` using `pdf` and `cdf` on the draw margin (margin = 0 for pure win/loss, or configurable).
        2. Update `mu` and `sigma` for both items.
    - Ensure "beta" (performance noise) and "tau" (dynamics factor) are applied if configured.
    
    Test with manual cases (e.g., two fresh items, one wins -> verify direction of updates).
  </action>
  <verify>npx vitest run gaussian</verify>
  <done>Model correctly updates ratings (winner goes up, loser goes down, uncertainty decreases).</done>
</task>

<task type="auto">
  <name>Implement Engine Skeleton</name>
  <files>src/engine/index.ts, test/engine/core.test.ts</files>
  <action>
    Create the main `TasteEngine` class.
    - Props: `items` (Map), `config` (RunConfig), `rng` (RNG).
    - Method: `addItems(items: ItemInput[])` - initializes items with default mu/sigma.
    - Method: `submit(winnerId, loserId)` - calls `computeUpdate` and applies changes.
    
    Write a basic integration test: Add 2 items, submit a result, check ratings changed.
  </action>
  <verify>npx vitest run core</verify>
  <done>Engine can ingest items and process a basic vote.</done>
</task>
