# Plan 1.1: Foundation (Types, Math, RNG)

## Objective
Establish the mathematical and structural foundation for the Taste Engine. This involves implementing the statistical functions required for the Gaussian updates (erf/erfinv) and verifying/upgrading the deterministic RNG. We will refactor existing types and utilities to support this.

## Context
- .gsd/SPEC.md
- src/types.ts (Exists)
- src/utils/random.ts (Exists, uses XOR shift)
- src/utils/statistics.ts (To be created)

<task type="auto">
  <name>Implement Statistical Utils</name>
  <files>src/utils/statistics.ts, test/utils/statistics.test.ts</files>
  <action>
    Create `src/utils/statistics.ts`.
    Implement zero-dependency statistical functions needed for TrueSkill-like updates:
    - `erf(x)`: Error function (Abramowitz & Stegun 7.1.26 or similar).
    - `erfinv(x)`: Inverse error function (Acklam's algorithm).
    - `pdf(x)`: Standard normal PDF.
    - `cdf(x)`: Standard normal CDF (using erf).
    - `ppf(x)`: Inverse CDF (using erfinv).
    
    Add safeguards: Clamp `erfinv` inputs to avoid Infinity/NaN for extreme values.
    Write unit tests verifying these against known standard normal table values.
  </action>
  <verify>npx vitest run statistics</verify>
  <done>All statistical functions pass tests with high precision.</done>
</task>

<task type="auto">
  <name>Upgrade/Verify RNG</name>
  <files>src/utils/random.ts, test/utils/random.test.ts</files>
  <action>
    Review `src/utils/random.ts`.
    - Current: XOR shift.
    - Upgrade to **Mulberry32** for better statistical properties (32-bit state, passes small crush).
    - Ensure `seededRng` returns a deterministic function.
    - Add `nextFloat()`, `nextInt(min, max)` helpers if missing.
  </action>
  <verify>npx vitest run random</verify>
  <done>RNG is deterministic and upgraded.</done>
</task>
