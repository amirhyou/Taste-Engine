# Plan 3.1: Release Infrastructure (Docs & Versioning)

## Objective
Set up the automated documentation and versioning infrastructure for the monorepo to ensure professional release standards.

## Context
- .gsd/SPEC.md
- .gsd/phases/3/RESEARCH.md
- package.json
- packages/core/package.json

## Tasks

<task type="auto">
  <name>Setup TypeDoc</name>
  <files>
    - typedoc.json
    - package.json
  </files>
  <action>
    - Create a root `typedoc.json` with `entryPointStrategy: "packages"`.
    - Configure entry points for `packages/*`.
    - Add a `docs:generate` script to the root `package.json`.
    - Ensure it ignores `node_modules` and properly merges package docs.
  </action>
  <verify>npm run docs:generate</verify>
  <done>A `docs/api` directory is generated containing HTML documentation for all packages.</done>
</task>

<task type="auto">
  <name>Setup Changesets</name>
  <files>
    - .changeset/config.json
    - package.json
  </files>
  <action>
    - Install `@changesets/cli` in the root.
    - Initialize changesets using `npx changeset init`.
    - Configure the changeset to use `access: "public"` for packages.
    - Add `release` and `version` scripts to the root `package.json`.
  </action>
  <verify>npx changeset status</verify>
  <done>Changesets is initialized and tracking the monorepo packages.</done>
</task>

## Success Criteria
- [ ] `npm run docs:generate` successfully creates API documentation.
- [ ] Changesets is initialized and ready for versioning.
